## ការងារមួយពីដើមដល់ចប់

1. **បន្ថែមអតិថិជន៖** ហាង → អតិថិជន → អតិថិជនថ្មី។ បញ្ចូលឈ្មោះ និងទូរស័ព្ទ។
2. **បង្កើតការបញ្ជាទិញ៖** ការបញ្ជាទិញ → ការបញ្ជាទិញថ្មី។ ជ្រើសអតិថិជន ដាក់ឈ្មោះការងារ បន្ថែមមុខទំនិញ ចំនួន និងតម្លៃរាយ។ ការបញ្ជាទិញថ្មីចាប់ផ្ដើមជា **តារាងតម្លៃ**។
3. **ផ្ញើតម្លៃ៖** បើកការបញ្ជាទិញ រួចចុច **PDF តារាងតម្លៃ**។
4. **ទទួលការងារ៖** ចុច **ទទួលការបញ្ជាទិញ**។ វាចូលក្នុងជួរកាត់។
5. **រៀបចំឯកសារកាត់៖** នៅផ្ទាំង ដំណើរការ នាំចូល SVG រៀប ពិនិត្យ និងនាំចេញ TAP។ បន្ទាប់មកកែការបញ្ជាទិញ ហើយជ្រើស **គម្រោងកាត់**។
6. **កាត់៖** ផលិតកម្ម → ចុច **ចាប់ផ្ដើមកាត់** ហើយពេលចប់ចុច **បញ្ចប់**។ កម្មវិធីគិតនាទីពិតឱ្យ។
7. **កត់ស្នោ៖** បើកការបញ្ជាទិញ → **កត់ស្នោដែលប្រើ**។
8. **ទទួលប្រាក់៖** បើកការបញ្ជាទិញ → **កត់ការទូទាត់**។ ចុច **PDF វិក្កយបត្រ** បើត្រូវការ។
9. **ប្រគល់៖** ចុច **សម្គាល់ថាបានប្រគល់**។

## ស្តុកស្នោ

1. ស្តុកស្នោ → សម្ភារៈថ្មី។ បញ្ចូលឈ្មោះ ទំហំ ថ្លៃក្នុងមួយសន្លឹក និងចំនួនព្រមាន។
2. ចុច **ចូល/ចេញស្តុក** នៅពេលទិញស្នោ ឬយកចេញ។
3. **កែតាមការរាប់** ប្រើនៅពេលរាប់ស្តុកពិត ហើយចំនួនខុសពីកម្មវិធី។

ផ្ទាំងសង្ខេបបង្ហាញការព្រមាន នៅពេលស្តុកនៅត្រឹម ឬតិចជាងចំនួនព្រមាន។

## ប្រាក់ និងរបាយការណ៍

- **ប្រាក់** បង្ហាញអ្នកដែលជំពាក់ ការទូទាត់ និងចំណាយ។
- **របាយការណ៍** ជ្រើសថ្ងៃចាប់ពី និងដល់។ ប្រាក់ទទួល និងចំណាយគិតតាមថ្ងៃបង់ មិនមែនថ្ងៃចេញវិក្កយបត្រទេ។
- ចុចប៊ូតុង Excel ដើម្បីទាញយកឯកសារ CSV។ ចុច **PDF របាយការណ៍** ដើម្បីបោះពុម្ព។
- កម្មវិធីនេះមិនមែនជាប្រព័ន្ធគណនេយ្យ ឬពន្ធទេ។

## ការបម្រុងទុក (សំខាន់បំផុត)

1. ការកំណត់ហាង → **រក្សាឯកសារបម្រុង**។
2. ចម្លងឯកសារទៅ USB ឬកន្លែងផ្សេងពីកុំព្យូទ័រនេះ។
3. ធ្វើយ៉ាងហោចណាស់មួយសប្ដាហ៍ម្ដង។ កម្មវិធីរំលឹកបន្ទាប់ពី 7 ថ្ងៃ។

ឯកសារបម្រុងមានឈ្មោះអតិថិជន និងប្រាក់ ជាអក្សរធម្មតា។ សូមរក្សាឱ្យមានសុវត្ថិភាព។ ដើម្បីស្ដារ ចុច **ស្ដារពីឯកសារបម្រុង**។ ការស្ដារជំនួសទិន្នន័យហាងទាំងអស់ និងប្រើសម្រាប់ផ្លាស់ទៅឧបករណ៍ថ្មីបាន។ គម្រោងកាត់មានឯកសារបម្រុងដាច់ដោយឡែកនៅជំហាននាំចេញ។

## សុវត្ថិភាពម៉ាស៊ីន

កម្មវិធីនេះមិនធានាថា G-code មានសុវត្ថិភាពទេ។ វាមិនទាន់បានសាកលើ Mach3 ឬម៉ាស៊ីនពិតឡើយ។ រាល់ការងារថ្មី៖

1. ពិនិត្យ F និង S ឱ្យត្រូវនឹងខ្សែ និងស្នោ។
2. កំណត់ចំណុចសូន្យនៅជ្រុងស្នោ និងពិនិត្យថាក្បាលមិនបុកឧបករណ៍គៀប។
3. បើកឯកសារក្នុង Mach3 និងប្រៀបធៀបនឹងរូបក្នុងកម្មវិធី។
4. រត់ស្ងួតដោយមិនដាក់កម្ដៅខ្សែ ហើយដាក់ដៃជិតប៊ូតុងឈប់។
5. កាត់ស្នោសាកមុន នៅពេលប្ដូរការកំណត់។
6. នៅជិតម៉ាស៊ីន និងឱ្យមានខ្យល់ចេញចូល។ ផ្សែងស្នោមានគ្រោះថ្នាក់។
